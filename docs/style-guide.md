# Style Guide

- 모바일 퍼스트로 작성한다.
- 앱 콘텐츠 최대 너비는 430px을 기준으로 한다.
- Tailwind CSS를 우선 사용한다.
- 인라인 스타일은 특별한 이유가 없는 한 사용하지 않는다.
- 반복되는 색상, 간격, 폰트는 디자인 토큰으로 관리한다.
- 공통 버튼, 입력창, 카드 스타일을 재사용한다.

## 접근성

- 클릭 요소는 적절한 `button` 또는 링크 요소를 사용한다.
- 이미지에는 의미 있는 `alt`를 제공한다.
- 입력 요소는 `label`과 연결한다.
- 아이콘 버튼에는 `aria-label`을 제공한다.
- 키보드로 주요 기능을 사용할 수 있어야 한다.
- 색상만으로 상태를 구분하지 않는다.
