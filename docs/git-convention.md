```text
main
develop
feature/login
feature/onboarding
feature/home

```

## 커밋 타입

```text
Feat
Fix
Docs
Style
Refactor
Test
Chore
```

예시:
```text
Feat: 온보딩 관광 취향 선택 화면 구현
Fix: 코스 상세 좋아요 상태 동기화 오류 수정
Docs: Claude 개발 규칙 추가
```
